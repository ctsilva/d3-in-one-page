# Tutorial data

`skubal.csv` and `skubal.js` hold 495 pitches thrown by Tarik Skubal (MLB ID 669373)
in five regular-season games, August 10 to September 3, 2026. Both are generated by
`make_data.py` from the full 119-column Statcast export, keeping 22 columns and
changing nothing else. Do not edit them by hand.

## Source and copyright

The data comes from [Baseball Savant](https://baseballsavant.mlb.com), Major League
Baseball's Statcast site, downloaded on September 8, 2026 with
[Statcast search](https://baseballsavant.mlb.com/statcast_search). It is copyright
MLB Advanced Media, L.P.

This excerpt is included for teaching and non-commercial educational use. We claim
no ownership of the data and do not redistribute the full dataset; download it from
Baseball Savant for anything beyond following the tutorial.

[Statcast field definitions](https://baseballsavant.mlb.com/csv-docs) describe every
column and its units.

## Reproducing the download

[This Statcast search query](https://baseballsavant.mlb.com/statcast_search/csv?all=true&type=details&player_type=pitcher&pitchers_lookup%5B%5D=669373&game_date_gt=2026-08-08&game_date_lt=2026-09-07&hfSea=2026%7C&hfGT=R%7C&group_by=name&min_pitches=0&min_results=0)
returns the same 119-column CSV (pitcher 669373, regular season, August 8 to
September 7, 2026). Save it as `data/statcast_export.csv` (ignored by git) and run
`python3 make_data.py` from this directory, or pass the path to the script as its
only argument.
